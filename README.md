# Coach Toolkit

校長 Coach 工具箱：公開工具卡。紀錄與錄音只存使用者手機，不在此 repo。

匯出 Word：產生教案工具卡後，有兩種輸出可選——「精簡版」（只留要問的問句與要點，約 3 頁）與「完整版」（另含預想學生回應、接續、診斷，約 5 頁）。A4、全文 14 號字，可再編輯。入口：「教案」頁、「已存教案」清單、「工具卡」頁的教案橫幅。檔案在手機端直接產生，不經過任何伺服器。

說課／議課模式：「教案」頁可選「說課」（老師尚未上課，預先釐清並理解自己的設計想法，內容用「如果上課時…」的預想語氣）或「議課」（上課後回顧討論）。已存教案會記住當時的模式；舊的已存教案視為議課。
